Sandbox isolation spec

          
    
            
  • Process boundary: legacy code never runs in the server process, only in pooled worker processes.
    • 
            
  • Memory: 256 MB heap cap per worker (--max-old-space-size=256); an overrun is MEMORY_EXCEEDED.
    • 
            
  • Time: 3000 ms watchdog per probe; the worker is killed and respawned on TIMEOUT.
    • 
            
  • Realm: a fresh node:vm context per probe, null-prototype globals, no require, process reduced to { env: {} }.
    • 
            
  • Network & disk: outbound network blocked; host file system writes blocked outside /tmp/lazarus-sandbox.
    • 
            
  • Modules: multi-file probes resolve only relative paths inside an in-memory module map.
    • 
            
  • Protocol: typed JSON-RPC 2.0 between the server and each worker, validated at runtime.
